# Standard Gold & Diamonds (SFJ) — Landing Page

> **Timeless Elegance. Crafted for You.**  
> Boutique jewellery showroom in Payyavoor, Kannur, Kerala (670633).

This is a production-ready, mobile-first landing page crafted strictly in accordance with the PRD and grounded in the `frontend-design` principles:
* **Palettes:** Rich Black (`#0A0A0A`), Royal Gold (`#D4AF37`), Light Gold (`#F1D77A`), Deep Gold (`#A67C00`), Ivory (`#FAF6EC`), and Showroom Walnut (`#5A3A22`).
* **Typography:** Editorial `Cormorant Garamond` serif headings paired with clean, legible `Poppins` body type.
* **Anti-Cliché Design:** Eliminates generic AI tropes (no fake arrow tails on buttons, no all-caps eyebrows, no single-word colored hero headlines, no sequential numbering on non-ordered lists).
