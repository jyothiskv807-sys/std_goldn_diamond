7. INTERACTIVE FEATURES, ANIMATIONS & JAVASCRIPT LOGIC
================================================================================

1. Responsive Mobile Drawer:
   - Hamburger icon on mobile (< 768px) smoothly toggles the `#mobileMenuDrawer` with
     backdrop blur and scroll locking on `document.body`.
   - Automatically closes when any menu item is tapped.

2. Dynamic Navbar Glassmorphism on Scroll:
   - When user scrolls past 40px, `#mainHeader` transitions from transparent to solid
     dark glassmorphism (`bg-[#0A0A0A]/95`, `backdrop-blur-md`, `border-b border-[#D4AF37]/20`).

3. Active Navigation Highlighting:
   - Intersection logic tracks scroll position across `#collections`, `#bridal`, `#about`,
     `#why-us`, and `#visit-us`, dynamically applying gold active underline styles to
     the corresponding desktop menu link.

4. Scroll Reveal Animations (IntersectionObserver):
   - `.reveal-on-scroll` triggers when elements enter 12% of the viewport, applying
     smooth CSS transform (`translateY(0)` from `translateY(24px)`) and opacity fade-in.

5. Malayalam Language Toggle:
   - Tapping "🌐 മലയാളം" in the header dynamically toggles visibility of `.lang-ml`
     elements across the page, providing bilingual Malayalam accents for native Kerala
     visitors, and toggles the button label to "EN".

6. One-Click Phone Number Copy:
   - Tapping the "Copy" button next to 094472 51916 invokes the Clipboard API, copying
     the plain number and displaying a momentary "Copied +91 94472 51916!" confirmation.

7. Micro Hover Animations:
   - `.sheen-btn`: Shimmering light reflection sweeps across gold buttons on hover.
   - `.hover-elevate`: Luxury cards lift by -4px to -6px with gold drop-shadows.
   - `.pulse-ring-effect`: Floating WhatsApp action button radiates continuous pulsating gold rings.
